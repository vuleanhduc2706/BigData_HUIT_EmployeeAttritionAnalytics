MapReduce Model BM KHDL Trang  3 MapReduce is a distributed programming model used to process large datasets across multiple computers in a cluster. Main idea: Map: Processes input data and generates key–value pairs. Shuffle: Groups the data based on the key. Reduce: Aggregates or summarizes the results.

=== SLIDE 4 ===
MapReduce Model BM KHDL Trang  4 Problem : Calculating total revenue by product Assume each record has the following format: Order_ID ,  Product_Name , Quantity,  Unit_Price Example: 	001, Laptop, 2, 1500 	002, Mouse, 3, 20 	003, Laptop, 1, 1500

=== SLIDE 5 ===
MapReduce Model BM KHDL Trang  5 Map Output : The Map phase reads each record, calculates the revenue for that product (Quantity ×  Unit_Price ): (Laptop, 3000) (Mouse, 60) (Laptop, 1500) Shuffle Phase : The Shuffle phase groups all values that share the same key: Laptop → [3000, 1500] Mouse → [60] Reduce Phase : The Reduce phase aggregates the values for each key by summing them to obtain the total revenue per product: (Laptop, 4500) (Mouse, 60)
